## Project Structure

```
Portfolio/
├── index.html    # page structure and content
```

## Run Locally

No build step or dependencies needed.

```bash
git clone https://github.com/VIBHA-2612/Portfolio.git
cd Portfolio
```

Then open `index.html` in your browser.

## Updating the Resume

Replace `resume.pdf` with the new file (keep the same name), then commit and push.
